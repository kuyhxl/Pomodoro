# FreeRTOS Pomodoro (Windows/MSVC)

FreeRTOS 태스크를 이용해 공부 시간과 휴식 시간을 관리하는 Windows 콘솔용 Pomodoro 데모입니다. 사용자 입력, 세션 상태 관리, 카운트다운, 상태 표시 및 파일 로그 기록을 별도의 태스크로 처리합니다.

## 주요 기능

- 공부/휴식 세션과 `IDLE`, `SETTING`, `STUDYING`, `PAUSED`, `ALARM`, `BREAK` 상태 관리
- 공부 시간 및 휴식 시간 설정
- 사용자 부재/복귀 입력을 이용한 일시 정지와 재개 시뮬레이션
- 완료한 Pomodoro 횟수와 누적 시간 표시
- 알람 처리와 `pomodoro_log.txt` 기록
- FreeRTOS 큐와 세마포어를 이용한 태스크 간 이벤트 및 상태 동기화

초기 설정은 **공부 25초, 휴식 5초**입니다. 빠르게 동작을 확인하기 위한 데모 값이며, 키보드 입력으로 변경할 수 있습니다.

## 키보드 조작

숫자를 먼저 입력한 뒤 시간 단위를 지정합니다. 예를 들어 `25m`는 공부 시간 25분, `5T`는 휴식 시간 5초입니다.

| 키 | 동작 |
| --- | --- |
| `숫자` + `t` | 공부 시간을 초 단위로 설정 |
| `숫자` + `m` | 공부 시간을 분 단위로 설정 |
| `숫자` + `T` | 휴식 시간을 초 단위로 설정 |
| `숫자` + `M` | 휴식 시간을 분 단위로 설정 |
| `c` | 입력 중인 숫자 취소 |
| `g` | 세션 시작 또는 재개 |
| `x` | 세션 중지 후 대기 상태로 복귀 |
| `a` | 알람 확인. 공부 종료 후에는 휴식을 시작하고, 휴식 종료 후에는 대기 상태로 복귀 |
| `p` / `r` | 사용자 부재 / 복귀 시뮬레이션. 상태 변경은 해당 입력이 3초 연속 확인된 뒤 반영됩니다. |
| `z` | 카운트다운 초기화 및 대기 상태로 복귀 |
| `d` | 공부/휴식 시간을 기본값으로 복원 |
| `k` | 완료 횟수와 누적 시간 카운터 초기화 |
| `h` | 도움말 표시 |
| `q` | 프로그램 종료 |

## 빌드 및 실행

이 저장소에는 Pomodoro 데모 파일만 포함되어 있습니다. Visual Studio 프로젝트는 FreeRTOS 커널, 공용 데모 코드 및 FreeRTOS-Plus-Trace 파일을 **상대 경로로 참조**하므로, 이 저장소만 단독으로 내려받으면 빌드할 수 없습니다.

1. 공식 [FreeRTOS 저장소](https://github.com/FreeRTOS/FreeRTOS)를 내려받습니다.
2. 이 저장소의 파일을 FreeRTOS 트리 안의 `FreeRTOS/Demo/WIN32-MSVC-Pomodoro` 위치에 배치합니다. 주변의 `FreeRTOS/Source`, `FreeRTOS/Demo/Common`, `FreeRTOS-Plus/Source/FreeRTOS-Plus-Trace` 경로도 유지되어야 합니다.
3. `WIN32.sln`을 Visual Studio에서 엽니다. Visual Studio의 **Desktop development with C++** 워크로드와 Windows SDK가 필요합니다.
4. `Debug` 또는 `Release`, `x64` 또는 `Win32` 구성을 선택해 빌드하고 실행합니다.
5. 실행되는 콘솔 창에서 `h`를 눌러 도움말을 확인합니다.

## 로그 및 시뮬레이션 안내

- 세션 종료 알람이 발생하면 실행 작업 디렉터리에 `pomodoro_log.txt`가 추가됩니다.
- 외부 앱 동기화 메시지는 콘솔에 출력되는 데모 동작이며 실제 외부 서비스와 통신하지 않습니다.
- 사용자 존재 감지는 실제 센서가 아니라 `p`와 `r` 키로 시뮬레이션합니다. 상태 변경 전 입력을 1초 간격으로 3회 확인합니다.
